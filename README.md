# MiniProject_DS_AIML-B_2026_TourismTrend
# Tourism Trend Analysis and Visualization

## Abstract
This project focuses on analyzing tourism trends by studying country-wise tourist arrivals to India over multiple years. The dataset contains visitor data from different countries between 2014 and 2020. The main objective is to identify patterns, trends, and variations in tourist inflow.

The data was cleaned and transformed from wide format to long format using preprocessing techniques. Exploratory Data Analysis (EDA) was performed to understand trends over time, identify top contributing countries, and analyze growth patterns. Various visualizations were created using graphs to make the data easier to interpret.

The results show that countries like the U.S.A and U.K contribute a major share of tourists to India. A steady increase in tourism was observed from 2014 to 2019, followed by a decline in 2020 due to external factors. This project helps in understanding tourism behavior and supports better planning and decision-making.

---

## Problem Statement
It is difficult to understand tourism patterns and predict tourist inflow without proper data analysis. This project aims to analyze tourism data to identify trends and patterns in tourist arrivals to India.

---

## Dataset Source
The dataset used in this project contains country-wise yearly tourist arrivals to India from 2014 to 2020. The data was collected from an open dataset available on Kaggle.
